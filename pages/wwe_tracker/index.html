Add match cards

      
This is what makes search find an actual match rather than a date range. Paste one row per episode:
      show,date,title,card — the card is a free-text list of what happened, and every word in it becomes searchable.

      
Example: event,2009-06-28,The Bash 2009,CM Punk vs Jeff Hardy World Heavyweight Title; Randy Orton vs Triple H

      
Rows that match an existing show and date get corrected in place. Rows with a new date get added. Cagematch and Wikipedia results tables paste into this shape with light editing.

      
      

        
        
      

    


    

      
Import weekly episodes from TMDB

      
Wikipedia covers pay-per-views well and weekly television barely at all. TMDB is the other way
      round — it carries Raw and SmackDown episode by episode with air dates, titles, recap text and
      stills, one season per year, which is how this catalogue is already built.

      
You need your own free key from themoviedb.org → Settings → API. Mine would be
      visible in this file and revoked within a day. It is kept in plain storage on this device, since a
      read-only key is not worth encrypting.

Fill in episode data

      
WWE event articles on Wikipedia carry the full results table in their source, so one request per
      event returns the description, the real date and every match on the card together. This is the way to
      populate the database — typing it in was never realistic.

      
Events first: there are a few hundred and almost all of them have articles.
      Weekly episodes are thinner — Wikipedia covers notable Raws and little else — so expect most
      of those to come back empty. Nothing is written unless the article's year matches the episode.

      

        
        
        
      

      

    


    

      
Fix event dates only

      
Every pay-per-view date except WrestleMania is a guess at which Sunday it fell on. Wikipedia states
      the real date in the opening line of each event's article, so this reads it and corrects the ledger.
      A date is only accepted within 120 days of the estimate, so a mismatched article cannot quietly move
      an event to the wrong year.

      

        
        
      

      

    


    

      
Episode numbering

      
The generator assumes a weekly show never missed its slot. Raw did — it ran 20 episodes ahead
      of reality by 2012. Anchors pin numbering to dates you know are right and spread the correction between
      them. Weeks where two episodes share a number are marked “Number approx.” in the ledger.
